# pnu-docs-chatbot

공공기관 및 부산대 규정/행정 문서 검색 챗봇 졸업과제입니다.

## Frontend

산지니 마스코트를 활용한 부산대 문서 검색 챗봇 UI MVP입니다.

- React + Vite + TypeScript
- mock 기반 대화 응답
- 답변 신뢰도 및 근거 문서 패널
- 최신 문서 우선 토글
- 모바일 대응 drawer 레이아웃
- 프롬프트 탈취/범위 밖 질문에 대한 안전 응답 mock

## Run

```bash
npm install
npm run dev
```

PowerShell 실행 정책에 막히는 환경에서는 `npm.cmd`를 사용합니다.

```bash
npm.cmd install
npm.cmd run dev
```
