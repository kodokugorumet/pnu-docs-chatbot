# 프론트엔드 UX/UI 개편 및 검증

질문 입력과 답변 읽기를 중심으로 화면을 재구성했다. 왼쪽에는 실제 대화 기록을,
가운데에는 질문·답변을 배치하고 모델·역할·검색 옵션은 설정으로 옮겼다.
산지니와 PNU 블루를 유지하면서 텍스트 대비, 여백, 모바일 탐색을 정리했다.

## 사용자에게 달라진 동작

- 추천 질문을 누르면 기관과 질문이 입력되고, 수정 후 전송할 수 있다.
- 대화 검색·전환·삭제·되돌리기와 최근 30개 대화의 브라우저 저장·복원을 지원한다.
- 답변의 목록·표·강조를 Markdown으로 읽고, 출처 번호로 해당 문서에 바로 이동한다.
- 답변 복사, 원래 요청 조건을 유지한 재시도·재생성, 생성 중지, 최신 답변으로 이동을 지원한다.
- 연결 전에도 초안을 작성할 수 있다. 서버 준비 상태에 따라 전송 가능 여부를 표시한다.
- Enter 전송, Shift+Enter 줄바꿈, 한글 조합 중 전송 방지, 모달 Escape 닫기와 근거 탭의 방향키 탐색을 지원한다.

대화는 이 브라우저의 localStorage에만 저장된다. `/chat`은 질문별로 독립 요청하며,
여러 대화의 문맥을 서버에 합쳐 보내는 기능은 추가하지 않았다.

## 최종 자동 검증

Node.js 24.21.0에서 `npm run check`를 실행해 종료 코드 0을 확인했다.

| 검사 | 결과 |
| --- | --- |
| 프론트엔드 회귀 테스트 | 101개 통과, 건너뜀 없음 |
| V8 문장 커버리지 | 100% — 706/706 |
| V8 분기 커버리지 | 100% — 790/790 |
| V8 함수 커버리지 | 100% — 230/230 |
| V8 라인 커버리지 | 100% — 664/664 |
| 기존 Python 회귀 테스트 | 862개 실행, 성공 856개·조건부 건너뜀 6개 |
| ESLint·앱 및 테스트 TypeScript 검사 | 통과 |
| Vite production build | 통과 |
| npm audit | 알려진 취약점 0건 |
| git diff --check | 통과 |

커버리지 범위는 이번에 수정·추가한 실행 코드 11개 파일이다:
`App`, `AnswerContent`, `CitationLocation`, `ChatComposer`, `ChatSidebar`,
`Dialog`, `useConversations`, `conversations`, `messageValidation`,
`presentation`, `settings`.
CSS·타입 선언·검증 도구 코드와 수정하지 않은 API/백엔드는 이 수치에 포함하지 않는다.
커버리지 제외 주석이나 건너뛴 프론트엔드 테스트는 없다.

HTML 보고서: `coverage/frontend/index.html`.

## 추가 검증 및 수정한 문제

| 기법 | 확인 내용 및 수정 |
| --- | --- |
| 무작위 상태 조작 | 고정 seed로 300개 대화 조작 시퀀스 검사. 기록이 30개 찬 상태에서도 오래된 삭제 대화를 복원하고 올바르게 선택하도록 수정 |
| 잘못된 저장 데이터 | 임의 JSON 1,000개와 손상된 중첩 필드 검사. 모델·근거·인용·추적 정보의 타입을 검증하고 중복 ID를 제거해 복원 중 화면 오류 방지 |
| 비동기 경합·실패 주입 | 중복 전송·중복 모델 해제, 지연 응답·취소·연결 실패·복사 거부·저장 공간 부족 검사. 화면을 떠난 뒤 늦게 도착한 응답의 상태 갱신과 불필요한 상태 재요청 방지 |
| 요청 일관성 | 재시도 시 기관·역할·제공자·모델·파서·검색 방식 보존. 복원된 기관이 폐지됐을 때 화면 표시와 새 요청의 필터가 일치하도록 수정 |
| Markdown 보안·구조 | HTML 실행·추적 이미지 로드를 방지하고, 코드와 외부 링크 안의 인용 표기를 중첩 버튼으로 만들지 않도록 수정 |
| 접근성 자동 검사 | axe로 첫 화면·답변·설정·모바일 대화 목록·근거 문서·검증·위치 탭 검사. 제목 단계, 대화 로그·위치·연결 상태의 의미와 낮은 텍스트 대비 수정 |
| 실제 브라우저 조작 | 320×568, 390×844, 1280×800 및 기본 데스크톱 크기에서 확인. 가로 넘침, 모달 스크롤·포커스, 검색·복원·되돌리기, 복사·재시도·취소, 긴 답변 스크롤 검사 |

실제 브라우저 axe 검사에서 확인된 위반은 수정 후 0건이었다. 네이티브 모달의
화면 밖/가려진 요소 때문에 일부 대비 항목은 자동 판정이 불가능해 화면과 키보드
조작으로 함께 확인했다. 이는 모든 접근성을 자동 검증했다는 뜻은 아니다.
검증용 브라우저에서 JavaScript 오류·경고 로그는 없었다.

## 재실행

Node.js 24 LTS가 PATH에 있어야 한다.

```bash
npm run test:coverage
npm run check
npm audit
```

브라우저 검사: 개발 서버에서 `/tests/frontend/browser-audit.html`을 열고
`접근성 검사 실행`을 누른다. 모달 안에서는 F8로 다시 검사할 수 있다.
상세 결과는 DOM의 `#accessibility-report`에 JSON으로 기록된다.
이 검증 진입점은 production bundle에 포함되지 않는다.

실제 AI 서버는 실행되지 않은 상태였으므로 프론트엔드 요청 흐름은 로컬 API 대역으로
검증했다. 테스트 답변에는 예시임을 명시했고, 검증용 서버와 탭은 종료했다.
실제 모델 호출 품질 및 운영 배포는 이번 검증 결과에 포함하지 않는다.
